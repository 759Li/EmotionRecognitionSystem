# 微表情识别模型训练结果报告

## 1. 实验目的

本实验旨在基于人脸68个关键点提取几何特征，利用LightGBM算法构建微表情七分类识别模型，并通过数据增强、特征选择、类别权重调整和交叉验证等策略提升模型泛化能力，最终评估模型在各类微表情上的识别性能。

## 3. 数据集与特征提取

### 3.1 数据集说明

- **表情类别**：angry, disgust, fear, happy, natural, sad, surprised（共7类）
- **原始图像数量**：约5.4万张
- **数据增强**：每张原图应用随机水平翻转（50%）、旋转±10°（50%）、高斯模糊（30%）、亮度对比度调整（30%），生成2个增强样本
- **处理后总样本数**：**161,094** 条

### 3.2 特征提取方法

使用dlib库检测68个面部关键点，提取三类几何特征：

| 特征类型 | 维度 | 描述 |
|---------|------|------|
| 全局点对距离 | 2278 | 68个关键点两两之间的欧氏距离（归一化后取上三角） |
| 局部区域手工特征 | 8 | 眼睛纵横比、嘴宽高比、眉毛高度比、鼻宽、下巴宽 |
| 左右对称性差异 | 2 | 左右眼纵横比绝对差、左右眉高度比绝对差 |
| **总计** | **2288** | |

特征提取后使用`StandardScaler`进行标准化。

## 4. 模型配置与训练策略

### 4.1 LightGBM超参数

| 参数 | 取值 | 作用 |
|------|------|------|
| boosting_type | gbdt | 梯度提升决策树 |
| objective | multiclass | 多分类任务 |
| num_class | 7 | 类别数 |
| max_depth | 7 | 限制树深度，防过拟合 |
| num_leaves | 63 | 叶子节点数 |
| learning_rate | 0.03 | 学习率 |
| lambda_l1 / lambda_l2 | 0.2 / 0.2 | L1/L2正则化 |
| feature_fraction | 0.7 | 每棵树随机采样70%特征 |
| bagging_fraction | 0.8 | 每轮随机采样80%数据 |
| bagging_freq | 5 | 每5次迭代执行bagging |
| min_child_samples | 10 | 叶子节点最小样本数 |
| metric | multi_logloss | 评估指标 |
| num_boost_round | 500 | 最大迭代次数 |
| early_stopping_rounds | 20 | 早停轮数 |

### 4.2 训练策略

- **类别不平衡处理**：使用`compute_class_weight('balanced')`计算类别权重，训练时传入样本权重
- **交叉验证与特征选择**：5折分层交叉验证训练5个模型，基于特征平均信息增益（gain）选择**前500个最重要特征**
- **最终模型训练**：使用选定的500个特征，按8:2分层划分训练集/验证集，重新训练LightGBM
- **模型保存**：保存最终模型、标准化器参数及特征选择索引

## 5. 训练过程记录

### 5.1 交叉验证各折性能

| 折叠 | 最佳迭代轮数 | 验证集multi_logloss |
|------|-------------|---------------------|
| Fold 1 | 500 | 0.81500 |
| Fold 2 | 500 | 0.82060 |
| Fold 3 | 500 | 0.81124 |
| Fold 4 | 500 | 0.81227 |
| Fold 5 | 500 | 0.81399 |
| **平均** | 500 | **0.81462** |

所有折叠均未触发早停（验证损失持续下降至500轮），表明模型仍有收敛空间。

### 5.2 最终模型训练

- 使用特征选择后的前500个重要特征
- 训练集/验证集划分：训练集 128,875 样本，验证集 32,219 样本
- 最终模型最佳迭代次数：500轮
- 验证集multi_logloss：**0.82569**（略高于交叉验证均值，因特征维度减少且训练集更大）

### 5.3 训练耗时（基于i7-12650H）

- 特征提取与增强：约 **2.5 小时**（单线程处理16万图像，含dlib关键点检测）
- 5折交叉验证训练：每折约 **4 分钟**，合计 **20 分钟**
- 最终模型训练：约 **3 分钟**
- **总训练时间（不含特征提取）：约 23 分钟**

> 特征提取是主要瓶颈（占总时间85%以上），LightGBM训练本身在CPU上已非常高效。

- **fear ↔ surprised**：互相误判显著（fear→surprised: 476；surprised→fear: 859），因两者都表现为眼睛睁大、眉毛抬高。
- **natural → happy/sad**：中性表情易被误判为轻微正向或负向表情（natural→happy: 1255；natural→sad: 1007），说明中性样本在特征空间中边界模糊。

## 7. 特征重要性分析

基于最终模型中特征的信息增益（gain），前20个最重要特征均为**全局点对距离**（`Column_X`），无一为手工设计的局部特征或对称性特征。

### 7.1 前10重要特征

| 排名 | 特征名 | 重要性值 | 对应关键点对（推测） |
|------|--------|----------|---------------------|
| 1 | Column_1 | 1309 | 关键点0与2（下巴左侧→下巴中央） |
| 2 | Column_11 | 1103 | 关键点0与12（下巴左侧→嘴角右侧） |
| 3 | Column_50 | 1051 | 关键点4与9（左眼下点→鼻尖下点） |
| 4 | Column_17 | 1027 | 关键点1与5（下巴左内→左眼外角） |
| 5 | Column_77 | 980 | 关键点7与11（右眉外→右嘴角） |
| 6 | Column_25 | 892 | 关键点2与8（下巴中央→鼻梁中） |
| 7 | Column_35 | 869 | 关键点3与9（下巴右内→鼻尖下） |
| 8 | Column_55 | 855 | 关键点5与10（左眼外角→右眼外角） |
| 9 | Column_75 | 810 | 关键点7与10（右眉外→右眼外角） |
| 10| Column_57 | 810 | 关键点5与12（左眼外角→右嘴角） |

### 7.2 重要发现

- **跨区域距离最判别**：不同面部区域之间的空间距离变化对微表情识别贡献最大，单一局部区域的比值特征信息量有限。
- **对称性信息未被突出**：虽然左右不对称可能是某些微表情的关键线索，但模型并未将对称性差异特征排入前20，可能因为这些特征已隐含在全局距离中。
- **手工特征贡献低**：8个手工区域特征均未进入前20，表明它们过于聚合，丢失了细微形变信息；保留原始点对距离更有利于模型自动学习判别模式。

## 8. 关于GPU加速的必要性讨论

尽管本机配备 **RTX 4060 8GB GPU**（支持CUDA 12.8），但本次训练**未启用GPU**，原因如下：

| 考量维度 | 评估 |
|---------|------|
| 训练数据规模 | 16万样本 × 500特征 = 仅8千万个浮点数，属于**中等规模** |
| LightGBM GPU加速门槛 | 官方建议百万级样本、数万特征时GPU才有明显优势 |
| 实际训练耗时 | CPU训练总耗时约23分钟，GPU加速后预期仅缩短至15~18分钟（<30%收益） |
| PCIe传输开销 | 每轮迭代需将数据从主存拷贝至显存（约320MB），树算法的串行部分会限制加速比 |
| 主要瓶颈 | 特征提取（2.5小时）占绝对主导，GPU无法加速dlib关键点检测和图像处理 |
| 改造代价 | 需重新编译LightGBM GPU版本，配置OpenCL/CUDA环境，可能破坏现有依赖稳定性 |

**结论**：当前任务**没有必要启用GPU**。若需进一步加速，应优先优化特征提取的并行化（多进程处理），而非切换到GPU训练。

## 9. 结论与改进建议

### 9.1 结论

- 成功构建了基于LightGBM的微表情七分类识别系统，在16万增强样本上取得 **84.5%的准确率**，加权平均F1为0.85。
- `happy`和`surprised`识别最佳（F1>0.87），`disgust`召回率最高（0.90）。
- 全局点对距离是最具判别力的特征类型，手工设计特征贡献微弱。
- 混淆模式符合面部表情生理学规律，`fear`与`surprised`、`angry`与`sad`易混淆。

### 9.2 改进建议

| 问题 | 建议方案 |
|------|----------|
| 模型500轮仍未收敛 | 增大`num_boost_round`至1000~2000，或提高学习率至0.05并配合早停 |
| 中性(`natural`)和恐惧(`fear`)精确率偏低 | 增加中性样本多样性；对恐惧表情禁用水平翻转（避免破坏方向性） |
| 手工特征贡献低 | 考虑移除手工特征，仅保留点对距离以降低维度 |
| 评估未使用独立测试集 | 从原始数据中划分20%作为独立测试集，交叉验证仅用于调参 |
| 特征提取效率低 | 使用`multiprocessing`并行化图像特征提取（可缩短至30~40分钟） |
| 模型集成未利用 | 使用5个交叉验证模型进行集成预测（`use_ensemble=True`），预期提升1~2%准确率 |
