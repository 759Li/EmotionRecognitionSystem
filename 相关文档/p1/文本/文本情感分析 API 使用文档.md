# 文本情感分析 API 使用文档
## 一、概述  
本 API 基于 StructBERT 预训练模型构建，专注于中文文本情感分析任务。通过核心函数 `analyze_text_emotion`，可自动识别文本中的情绪类别并输出详细的概率分布，支持将原始分类结果映射到标准化情绪体系。适用于用户评价分析、观点抽取、意图识别等多种 NLP 场景。  

**支持的情绪类别**（中英文对照）：  
- 恐惧（fear）、愤怒（anger）、厌恶（disgust）、中性（neutral）、悲伤（sadness）、高兴（happy）、惊讶（surprise）  


## 二、依赖库  
- `torch`：PyTorch 深度学习框架，用于加载模型并执行推理计算。  
- `transformers`：HuggingFace 提供的预训练模型接口库，支持模型与分词器的加载及文本编码。  
- `numpy`：用于数值计算，辅助处理概率分布与浮点误差修正。  


## 三、安装依赖  
使用以下命令安装所需依赖库：  
```bash
pip install torch transformers numpy
```


## 四、API 函数说明  
### `analyze_text_emotion(text, model_path)`  
#### 功能描述  
输入中文文本和模型路径，返回包含情绪概率分布、主导情绪、置信度等信息的分析结果。  

#### 参数说明  

| 参数名       | 类型   | 描述                                                                 |  
|--------------|--------|----------------------------------------------------------------------|  
| `text`       | string | 待分析的中文文本，应用层限制最长100个字符（超过100字自动截断），模型分词器最大支持128个token。 |  
| `model_path` | string | 预训练模型的本地路径（如 `./nlp_structbert_emotion_classification_chinese_base`）或 HuggingFace 模型仓库地址，需为 StructBERT 中文情感分类模型。 |  


#### 返回值  
返回字典类型，包含以下键值对：  

| 键名              | 类型   | 描述                                                                 |  
|-------------------|--------|----------------------------------------------------------------------|  
| `emotions`        | dict   | 情绪概率分布，键为情绪英文名称（如 "happy"），值为保留 8 位小数的概率字符串（如 "0.92345678"）。 |  
| `emotion_class`   | string | 主导情绪类别（英文名称，如 "anger"），即概率最高的情绪。              |  
| `confidence`      | float  | 置信度，即主导情绪的概率（保留 8 位小数）。                           |  
| `keywords`        | list   | 关键词列表（当前功能未实现，固定返回空列表 `[]`）。                    |  
| `face_count`      | int    | 人脸数量（文本分析无需人脸信息，固定返回 0）。                         |  
| `face_details`    | list   | 人脸详情（文本分析无需人脸信息，固定返回空列表 `[]`）。                |  


## 五、使用示例  
### 示例代码  
```python
from text_model import analyze_text_emotion

# 待分析文本
text = "排队半小时好不容易轮到我，前面的人居然直接插队还理直气壮，气得我攥紧了拳头，胸口像堵着一团火。"
# 模型路径（本地路径或HuggingFace仓库地址）
model_path = "nlp_structbert_emotion_classification_chinese_base"
# 调用情感分析函数
result = analyze_text_emotion(text, model_path)

# 输出结果
print(f"主导情绪类别: {result['emotion_class']}")
print(f"置信度: {result['confidence']}")
print("情绪概率分布:")
for emotion, prob in result['emotions'].items():
    print(f"  {emotion}: {prob}")
```

### 输出示例  
```
主导情绪类别: anger
置信度: 0.92345678
情绪概率分布:
  fear: 0.00123456
  anger: 0.92345678
  disgust: 0.03456789
  neutral: 0.01234567
  sadness: 0.00876543
  happy: 0.00012345
  surprise: 0.01953121
```


## 六、实现细节说明  
1. **模型推理流程**  
   ① 加载指定路径的 StructBERT 模型及配套分词器；  
   ② 对输入文本进行分词、编码（转换为模型可识别的张量格式），长度超过 128 字符时自动截断；  
   ③ 模型输出 logits 后，通过 softmax 函数计算原始情绪类别的概率分布；  
   ④ 将原始情绪映射到标准化体系（如“喜好”映射为“高兴”），并修正概率分布。  


2. **概率修正机制**  
   - 动态计算中性情绪概率：基于非中性情绪的概率极值差（最大值 - 最小值）归一化得到，确保中性情绪概率与文本情绪的“明确性”关联（情绪越明确，中性概率越低）。  
   - 误差修正：通过调整最大概率情绪的数值，确保所有情绪概率之和严格为 1.0，避免浮点计算误差。  


3. **情绪映射规则**  
   原始模型输出的 7 类情绪（恐惧、愤怒、厌恶、喜好、悲伤、高兴、惊讶）将映射到标准化体系，其中“喜好”会合并到“高兴”（happy），其余情绪直接对应同名类别。  


## 七、注意事项  
1. 模型路径需指向有效的 StructBERT 中文情感分类模型（如文件结构中的 `nlp_structbert_emotion_classification_chinese_base` 目录），否则会导致加载失败。  
2. 文本长度超过100字符时会被应用层截断；模型分词器max_length设为128，超过128个token的文本会在分词阶段被截断，可能影响长文本（如段落、多句对话）的分析准确性。
3. 模型在通用领域表现稳定，但对于专业术语密集的文本（如医疗、法律），情绪识别可能存在偏差。  
4. `keywords` 字段功能尚未开发，`face_count` 与 `face_details` 为适配多模态场景保留的字段，均不影响文本情感分析结果。
