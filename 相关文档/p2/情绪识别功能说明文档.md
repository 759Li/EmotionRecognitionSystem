# 情绪识别页面功能说明文档
## 一、功能概述
情绪识别页面是情绪识别系统的核心交互界面，支持通过文本、图片和实时视频三种模态进行情绪识别。系统可精准识别7类基础情绪（愤怒、厌恶、恐惧、喜悦、中性、悲伤、惊讶），并返回情绪标签及置信度，为用户提供多场景下的情绪分析服务。

## 二、页面结构
页面采用卡片式布局，主要包含以下核心区域：

| 区域 | 元素 | 功能描述 |
|------|------|----------|
| 导航栏 | 功能入口链接 | 包含“情绪识别”“历史记录”“数据看板”“用户中心”等导航项，当前页面高亮显示，支持快速跳转至其他功能页。 |
| 页面标题 | 主标题+副标题 | 显示“多模态情绪识别系统”及说明文字，明确页面功能。 |
| 模态卡片 | 文本/图片/视频分析卡片 | 每张卡片包含图标、标题、描述及“开始分析”按钮，点击触发对应模态框。 |
| 功能特点区 | 核心功能卡片 | 展示7类情绪识别、历史记录管理、数据可视化分析等系统特性。 |
| 模态框 | 文本/图片/视频分析界面 | 包含输入控件、分析按钮及结果展示区域，支持模态化交互。 |

## 三、交互流程
### 3.1 文本情绪分析
1. **触发模态框**：点击“文本情绪分析”卡片，弹出文本分析模态框。
2. **输入文本**：在文本框中输入中文文本（最长100字，实时显示字符计数）。
3. **提交分析**：点击“分析情绪”按钮，前端通过`/api/text/analyze`接口将文本发送至后端。
4. **结果展示**：
   - 显示主情绪标签（如“愤怒”）及置信度进度条。
   - 展示情绪概率分布（7类情绪的具体占比）。
   - 显示情绪关键词区域（当前版本关键词提取功能未实现，显示“未识别到情绪关键词”提示）。

### 3.2 图片情绪识别
1. **触发模态框**：点击“图片情绪识别”卡片，弹出图片分析模态框。
2. **上传图片**：通过点击或拖拽方式上传含人脸的图片（支持JPG/PNG格式）。
3. **预览与分析**：上传后显示图片预览，点击“分析图片”按钮，通过`/api/image/analyze`接口提交分析。
4. **结果展示**：
   - 标注图片中的人脸区域及情绪标签（如“喜悦”）。
   - 显示情绪置信度（保留2位小数）。
   - 支持多人脸场景，分别标注每幅人脸的情绪结果。

### 3.3 实时视频识别
1. **触发模态框**：点击“实时视频识别”卡片，弹出视频分析模态框。
2. **摄像头授权**：系统请求摄像头权限，获取实时视频流。
3. **参数设置**：可选择分辨率（640×480或320×240），点击“暂停”按钮可暂停/继续识别。
4. **实时分析**：
   - 系统定时检测视频帧中的人脸并识别情绪。
   - 实时显示当前情绪标签（如“惊讶”）及情绪强度（如“高唤醒高强度”）。
   - 视频帧中绘制人脸边界框及关键点，直观展示识别区域。

## 四、技术实现
### 4.1 前端交互
- **模态框控制**：使用JavaScript实现模态框的显示/隐藏，通过事件监听处理用户输入。
- **实时验证**：文本输入时限制长度（≤100字），图片/视频上传时校验格式。
- **结果可视化**：通过动态DOM操作展示情绪标签、置信度进度条及关键词，使用颜色编码区分情绪类型（如喜悦为绿色，愤怒为红色）。

### 4.2 后端接口
| 接口 | 方法 | 功能描述 |
|------|------|----------|
| `/api/text/analyze` | POST | 接收文本数据，返回情绪分析结果（主情绪、置信度、关键词）。 |
| `/api/image/analyze` | POST | 接收图片文件，返回人脸检测及情绪识别结果。 |
| `/api/video/upload` | POST | 接收前端录制的视频文件，保存并调用VideoProcessor进行情绪分析。 |

### 4.3 情绪识别模型
- **文本分析**：基于StructBERT预训练模型，对输入文本进行分词和特征提取，通过softmax计算情绪概率分布。
- **图片/视频分析**：采用LightGBM框架结合68点人脸关键点检测，提取几何特征并预测情绪类别（图片模式选取最大人脸进行分析）。

## 五、结果展示说明
情绪识别结果以直观方式呈现：
- **情绪标签**：使用彩色标签显示主情绪（如“喜悦”），标签颜色与情绪类型绑定（如`#66BB6A`对应喜悦）。
- **置信度**：通过进度条展示情绪置信度（0-100%），数值精确到小数点后2位。
- **关键词**：文本分析结果中预留关键词展示区域（当前版本关键词提取功能未实现）。
- **人脸标注**：图片/视频中通过绿色矩形框标注人脸区域，关键点以红色圆点标记。

## 六、注意事项
1. **输入限制**：
   - 文本长度不超过100字，超过部分自动截断。
   - 图片需包含清晰人脸，支持JPG/PNG格式，文件大小不超过5MB。
   - 视频识别依赖设备摄像头权限，建议在光线充足环境下使用，以提高识别精度。
2. **错误处理**：
   - 未检测到人脸时，图片/视频分析返回“未检测到有效人脸”提示。
   - 网络异常时，显示“分析失败，请稍后重试”并记录错误日志。
3. **性能优化**：
   - 视频识别默认每10帧间隔处理1帧，平衡精度与性能；低配置设备可选择320×240分辨率。
