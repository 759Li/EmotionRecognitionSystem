# 数据看板功能说明文档
## 一、功能概述
数据看板是情绪识别系统中用于可视化展示用户情绪识别数据的核心模块，通过图表形式直观呈现用户的情绪分布规律和时间变化趋势。用户可通过该页面快速掌握自身情绪识别记录的统计特征，包括各类情绪的出现频率及随时间的波动情况，为情绪管理提供数据支持。

## 二、页面结构
页面采用分区设计，主要包含导航栏、主内容区和页脚三部分，核心功能集中在主内容区的数据可视化展示：

| 区域 | 元素 | 功能描述 |
|------|------|----------|
| 导航栏 | 功能入口链接 | 包含“情绪识别”“历史记录”“数据看板”“用户中心”等导航项，当前页面高亮显示，支持快速跳转至其他功能页。 |
| 主内容区 | 页面标题 | 显示“数据看板”及副标题“查看情绪识别数据的统计和分析”，明确页面用途。 |
|  | 情绪分布统计卡片 | 包含标题“情绪分布统计”、描述文字“展示各类情绪的分布比例”及柱状图，以可视化方式呈现不同情绪类型的出现次数。 |
|  | 趋势分析卡片 | 包含标题“趋势分析”、描述文字“分析情绪随时间的变化趋势”及散点图，展示情绪类型随时间的分布情况。 |
| 页脚 | 版权信息 | 显示项目版权声明“© 2025 七情六欲项目组. 基于深度学习的人脸情绪识别系统”，提供项目归属信息。 |

## 三、交互流程
1. **页面访问**：用户通过点击导航栏中的“数据看板”链接或直接访问`/dashboard`路由进入页面。
2. **数据加载**：后端自动查询当前用户的所有情绪识别历史记录，进行数据解析和统计后，将情绪分布数据和趋势数据传递至前端。
3. **图表渲染**：
   - 情绪分布统计：前端使用ECharts绘制柱状图，X轴为情绪类型（愤怒、厌恶、恐惧、喜悦、中性、悲伤、惊讶），Y轴为对应情绪的出现次数，柱状图颜色按情绪类型固定映射（如愤怒为红色、喜悦为绿色）。
   - 趋势分析：前端使用ECharts绘制散点图，X轴为时间（按识别记录的创建时间排序），Y轴为情绪类型，每个散点代表一条记录，颜色与情绪分布图表保持一致，支持鼠标悬停查看具体时间和情绪信息。
4. **数据交互**：
   - 鼠标悬停在柱状图上时，显示该情绪的具体出现次数。
   - 鼠标悬停在散点图的点上时，显示对应记录的时间和情绪类型。
   - 图表支持响应式布局，在不同屏幕尺寸下自动调整大小和标签显示方式（如时间标签旋转避免重叠）。

## 四、技术实现
### 4.1 后端数据处理（app.py）
1. **数据查询**：通过`db_manager.get_user_recognition_history(user_id)`获取当前用户最近的识别记录（默认最多20条）。
2. **情绪分布统计**：
   - 遍历记录，解析每条记录的`result`字段（JSON格式），提取`emotion_class`。
   - 按情绪类型计数，生成`emotion_dist`字典（键为情绪类型，值为出现次数）。
3. **趋势数据处理**：
   - 提取每条记录的`created_at`（识别时间）和`emotion_class`，格式化时间为`YYYY-MM-DD HH:MM`格式。
   - 生成`trend_data`列表，每个元素包含时间和情绪类型信息。
4. **数据传递**：将`emotion_dist`和`trend_data`传递至`dashboard.html`模板。

### 4.2 前端图表渲染（dashboard.html）
1. **数据解析**：通过模板语法将后端传递的JSON数据转换为JavaScript对象（`emotionDistribution`和`trendData`）。
2. **情绪分布图表**：
   - 初始化ECharts实例，配置X轴（情绪类型）、Y轴（出现次数）及柱状图系列。
   - 定义颜色映射规则，确保每种情绪对应固定颜色（如`anger`对应`#FF5252`）。
   - 数据为空时显示“暂无数据”提示。
3. **趋势分析图表**：
   - 对时间进行排序（按时间戳升序），确保图表按时间顺序展示。
   - 配置散点图系列，X轴为排序后的时间，Y轴为情绪类型，散点颜色与情绪分布图表保持一致。
   - 支持图例显示，鼠标悬停时显示详细信息。

### 4.3 响应式设计
- 导航栏在屏幕宽度≤768px时自动调整为垂直布局，确保移动端适配。
- 图表容器宽度设为100%，随页面尺寸动态调整，避免内容溢出。
- 时间标签在小屏设备上旋转30度，优化显示效果。

## 五、数据来源与格式
1. **数据来源**：所有数据均来自用户的情绪识别历史记录，存储于数据库的`recognition_history`表，通过`user_id`关联当前登录用户。
2. **数据格式**：
   - 情绪分布：字典格式，如`{"happy": 15, "sadness": 8, ...}`。
   - 趋势数据：列表格式，如`[{"time": "2025-07-01 10:30", "emotionValue": "happy"}, ...]`。

## 六、注意事项
1. **数据为空处理**：当用户无识别记录时，图表显示“暂无数据”提示，避免图表渲染错误。
2. **情绪类型一致性**：前端情绪类型与后端保持一致（基于`EmotionClass`枚举），颜色映射固定，确保用户认知统一。
3. **性能优化**：历史记录较多时，通过后端分页查询限制数据量（默认最多加载最近20条记录），避免前端渲染卡顿。
4. **时间格式兼容**：对不同格式的时间字符串进行统一处理，确保排序准确性。
